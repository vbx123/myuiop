# استوديو الترجمة (Subtitle Studio)

## طريقة الحصول على APK
1. فك الضغط وارفع كل محتويات المجلد على مستودع GitHub جديد (فرع main) — تأكد إن مجلد `.github` اترفع.
2. روح تبويب **Actions** → سيبدأ بناء "Build APK" تلقائياً (أو شغّله من Run workflow).
3. بعد ما يخلص (3-6 دقايق) افتح العملية ونزّل من **Artifacts** الملف `SubtitleStudio-APK`، فك ضغطه وثبّت `app-debug.apk`.
